# Change Log

All notable changes to the "antigravity-project-snapshots" extension will be documented in this file.

## [1.0.0] - 2026-10-08

### Added
- Left-side status bar icons on Antigravity bottom bar (`$(trash)` and `$(history)`).
- Project-specific scope detection for any active workspace.
- Central global snapshot storage (`~/.antigravity-snapshots/<project>/`) ensuring zero workspace clutter.
- Side-by-side diff viewer for comparing snapshot versions against active workspace files.
- Visual Contents Dashboard webview panel with real-time search and filter tabs.
- 1-click single-file and all-files restore with automatic pre-restore safety checkpoints.
- Integration with Windows Desktop Recycle Bin via shell32 bridge.
